ЗАХВАТ КОРОЛЕВСТВ — 2D-стратегия для Android (APK), офлайн

ЧТО ВНУТРИ
- Лобби в стиле концепта: замок на фоне, кнопки «Играть», «Продолжить», «Коллекция карт», «Настройки», «Выход».
- Карта мира: 50 королевств по 10 этапов (500 уровней), дальше уровни продолжаются.
  Миниатюры королевств — это картинки уровней из концепта.
- Бой на 5 линиях. Спрайты армии, врагов, карт и фона взяты из концепт-картинки (папка assets).
- Карты (как в концепте): Пехотинец (1), Лучник (2), Кавалерия (3), Маг (4, урон 40 по врагу),
  Осадная машина (5, урон 30 по всем врагам), Огненный шар (3, урон 50 по линии),
  Защита (2, щит 50 на 5 ходов), Лечение (2, +40 HP замку).
- Враги (как в концепте): Гоблин-лучник, Орк, Тролль, Тёмный маг и босс Дракон на каждом 10-м этапе.
- Коллекция: улучшения армии (тап по юниту) и укрепление замка (+60 HP).
- Звёзды зависят от оставшегося HP замка. Монеты за победы. Всё сохраняется на телефоне.

КАК ИГРАТЬ
- Тап по карте, затем по линии (карты Защиты, Лечения и Осадной машины работают сразу).
- «Конец хода» — враги двигаются и атакуют, появляются новые волны. Мана +1 за ход.
- Если замок врага упал — победа. Если ваш замок — поражение.

СБОРКА APK (через Termux + GitHub, бесплатно)
1) Создайте репозиторий KingdomSiege на github.com (пустой).
2) В Termux:
     pkg install git
     unzip KingdomSiegeGame.zip && cd KingdomSiegeGame
     git init && git add . && git commit -m "game"
     git branch -M main
     git remote add origin https://github.com/ВАШ_ЛОГИН/KingdomSiege.git
     git push -u origin main
   Вместо пароля используйте Personal Access Token из настроек GitHub.
3) На github.com откройте вкладку Actions -> Build APK -> дождитесь зелёной галочки.
4) Скачайте артефакт KingdomSiege-apk (внутри app-debug.apk) и установите на телефон
   (разрешите установку из неизвестных источников).
